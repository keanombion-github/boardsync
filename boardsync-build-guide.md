# Boardsync Build Guide

Boardsync is a collaborative Kanban portfolio project. The goal is to learn and own the design from browser request to SQL and back.

- Read `Agents.md` and `Skills.md` for workflow and teaching depth.
- Read [current state](docs/project-state.md) for verified progress and the next checkpoint.
- Read [learning log](docs/learning-log.md) when checking understanding or resuming lessons.
- Read [architecture and roadmap](docs/architecture-roadmap.md) only for relevant conventions, schema, or design context. This preserves the previous guide; its historical status claims are superseded by current state.
- Manifests and code establish implemented behavior; the roadmap describes intent.

Continue with: "Continue guided development" or name a feature. Teach one concept and give a small task with observable acceptance criteria. Update verified state after meaningful work and learning evidence only after the user's demonstration. Do not paste the full roadmap into every chat.
